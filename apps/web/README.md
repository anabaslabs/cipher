# Cipher (Web)

Next.js frontend for the Cipher project.

## Setup

```bash
pnpm install
```

## Development

```bash
pnpm dev
# OR
turbo dev
```

## Build

```bash
pnpm build
# OR
turbo build
```

## Production

```bash
pnpm start
# OR
turbo start
```

## Usage

The web app runs at [http://localhost:3000](http://localhost:3000).
