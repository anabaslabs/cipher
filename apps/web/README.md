# Cipher (Web)

Next.js frontend for the Cipher project.

## Setup

```bash
cd apps/web
pnpm install
```

## Development

```bash
turbo dev
```

Or from the monorepo root:

```bash
turbo dev -F web
```

## Build

```bash
turbo build
```

Or from the monorepo root:

```bash
turbo build -F web
```

## Production

```bash
turbo start
```

Or from the monorepo root:

```bash
turbo start -F web
```

## Usage

The web app runs at [http://localhost:3000](http://localhost:3000).
